# Task Manager (Node.js + MySQL)

Fullstack Task Manager application built with Node.js, Express, MySQL and vanilla JavaScript.

---

## Features

- Create task
- Get all tasks
- Get single task
- Update task
- Delete task
- Toggle task completed directly from UI
- Edit task with auto redirect
- Loading states and improved UX

---

## Tech Stack

- Backend: Node.js, Express
- Database: MySQL
- Frontend: HTML, CSS, JavaScript
- Testing: Postman

---
